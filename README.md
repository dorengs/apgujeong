# 압구정 실거래 전광판

압구정 재건축 1~6구역(미성 · 신현대 · 구현대 · 한양)의 단지별·평형별 역대 최고가와 최근 거래를 보여 주는 화면입니다.
압구정동 현대아파트 전문 연세부동산중개법인(주) · 문의전화 02-542-3400

- 화면 주소: https://dorengs.github.io/apgujeong/
- 자료: 국토교통부 실거래가 공개시스템(아파트 매매 실거래가 상세 자료), 2006년 1월 이후 신고분, 계약일 기준

## 어떻게 돌아가나

| 위치 | 역할 |
|---|---|
| `site/` | 손님이 보는 화면(`index.html`, `logo.png`)과 자료(`data.js`). 이 폴더만 게시됩니다. |
| `scripts/update.mjs` | 국토부 자료와 서울부동산정보광장 토지거래허가 내역을 받아 `raw/`를 고치고 `site/data.js`를 새로 만듭니다. |
| `config/cfg.json` | 전용면적 → 현장 호칭 대응표, 집계에서 빼는 면적, 뜬 날 기록 시작일. |
| `raw/rows.json` | 받아 둔 압구정동 거래 전체. 거래마다 처음 나타난 날(`s`)을 함께 적습니다. |
| `raw/permits.json` | 토지거래허가 내역(강남구) 중 압구정 1~6구역 지번만 모은 것. 지번은 거래 자료에서 그 지번에 가장 많이 나온 단지로 이름을 붙입니다. |
| `.github/workflows/update.yml` | 평일 9시 47분·10시 47분·12시 47분·14시 47분·16시 47분, 토요일 9시 47분·10시 47분(한국 시간)에 자동으로 갱신하고 게시합니다. |

인증키는 저장소 **Settings → Secrets and variables → Actions**의 `MOLIT_KEY`에 들어 있습니다. 파일에는 적지 않습니다.

## 손으로 돌리기

**Actions → 전광판 갱신 → Run workflow**에서 받는 범위를 고릅니다.

- `auto`: 평소 최근 3개월, 월요일에는 최근 12개월
- 숫자: 최근 몇 개월
- `all`: 2006년 1월부터 전부 다시 받기(6분쯤 걸림)
- `permits`: 국토부 자료는 그대로 두고 토지거래허가 내역만 다시 받기

토지거래허가 내역을 받지 못한 날은 직전 내역이 그대로 남고, 전광판 갱신은 멈추지 않습니다.

## 호칭을 고치려면

`config/cfg.json`의 `cfg` 줄을 고칩니다. 한 줄의 형식은 `구역|단지|국토부 단지명|호칭|전용면적㎡(쉼표로 구분)|동`입니다.
고친 뒤 **Run workflow**를 한 번 돌리면 화면에 반영됩니다.

## 집계 규칙

- 계약 해제로 신고된 거래는 최고가와 최근 거래에서 뺍니다. 최고가가 같으면 더 최근 계약을 보여 줍니다.
- 신고가 표시는 계약 당시 그 평형의 종전 최고가를 넘긴 거래입니다.
- 뜬 날은 국토부 공개 자료에 거래가 처음 나타난 날이며 2026년 11월 14일부터 기록했습니다.
- 저층·코너 세대처럼 호칭이 없는 일부 면적은 평형별 집계에 넣지 않습니다(`config/cfg.json`의 `excluded`).
